# SCHOOLSOUL OS 2026.1.0
## INTELLECTUAL PROPERTY & ASSET CLASSIFICATION

**Product:** SchoolSoul OS  
**Current Release:** 2026.1.0  
**Project Attribution:** VINEXSAH TECHNOLOGIES project  
**Notice:** This document defines the classification boundaries between original project materials, third-party software, user-authored content, and tenant institutional records.

---

### Category A: SchoolSoul Original & Proprietary Project Materials

Attributed to the **SchoolSoul OS** project developed under the **VINEXSAH TECHNOLOGIES** project:
1. **Application Source Code:** All custom TypeScript and React components in `/src`, including custom layouts, dashboards, modals, navigation engines, and hooks.
2. **Backend Services & API Architecture:** Custom Express endpoints in `/server/routes`, data stores in `/server/db`, and custom services (`pesapalService.ts`, `marketFeeEngine.ts`, `liveLearningSocket.ts`).
3. **Database Architecture & State Machines:** Custom schemas, multi-tenant relational tables, and offline Dexie IndexedDB schemas.
4. **Security & RBAC Architecture:** 7-tier role matrix, route guards, token validation middlewares, and session timeout handlers.
5. **System Documentation & Blueprints:** All architectural blueprints, completeness matrices, audit logs, and release runbooks.
6. **SchoolSoul Brand Mark & UI Graphics:** Custom SVG brand assets, vector icons, and layout compositions.

---

### Category B: Third-Party & Open-Source Materials

Attributed to third-party rights holders and licensed under applicable open-source terms:
1. **Open-Source Libraries:** React, Express, Lucide React, Tailwind CSS, Dexie, PostgreSQL driver, jsonwebtoken, argon2, bcryptjs (see `THIRD_PARTY_COMPONENT_REGISTER.md`).
2. **Third-Party APIs:** Pesapal API 3.0 payment processing platform, Google GenAI SDK.
3. **Web Fonts & Typography:** Standard web safe typography and system fonts.

---

### Category C: User-Generated & Marketplace Content

Attributed to end users (students, teachers, parents, sellers):
1. **Student Marketplace Listings:** Product titles, descriptions, custom craft photographs, demonstration videos, and seller pricing.
2. **Student Portfolios & Projects:** STEM challenge entries, student essays, artwork uploads, certificates, and portfolio showcase items.
3. **Community Communications:** Direct messaging chat logs, announcement texts, forum posts, and feedback submissions.

*SchoolSoul OS claims no proprietary ownership over user-authored creative works.*

---

### Category D: School-Owned Institutional Data

Attributed to and exclusively owned by the respective school tenant:
1. **Student Academic Records:** Continuous assessment marks, grades, attendance roll-calls, exam transcripts, and official report cards.
2. **Institutional Financial Records:** School fee structures, invoice records, payment receipts, budget ledger entries, and bursary accounts.
3. **Staff & Personnel Records:** Staff HR profiles, leave requests, attendance logs, and performance appraisals.
4. **Safeguarding & Welfare Logs:** Confidential student welfare files, incident reports, and counselling records.

*SchoolSoul OS functions strictly as a data processor and software operating platform. All institutional records remain the exclusive property of the school tenant.*
